# DiPlay Geely E01 — v0.3.0-geely-rc

吉利星瑞 E01（ECARX E01 / MediaTek MT6735 / GKUI 19，**Android 5.1 / API 22**）的 CarPlay 车机端口。

> 早前文档把本车写成 Android 4.4，是错的 —— 实测 `ro.build.version.release=5.1`、`sdk=22`。
> 本 fork 仍保留 API 19 的支持底线（供其他老车机使用），但靶子是 5.1。

基于 `programmerguohuajing/DiPlay-Legacy-Android` **v0.2.7**，从上游 `shihabal3amri/DiPlay`
选择性移植了品牌无关的改进。

  **纯观察** —— 不改变连接超时、地址选择或重试行为。
- 文档重写为只描述本分支；上游的比亚迪功能清单、网站链接与预览文案已移除，
  GPL-3.0 / AGPL-3.0 归属声明保留。

## 安装

⚠️ **签名与官方 DiPlay APK 不同，无法覆盖安装。** 需先卸载：

```sh
adb uninstall com.shihab.diplay
adb install -r DiPlay-Legacy-Geely-V030.apk
```

卸载会丢失应用内设置（分辨率、音频缓冲、方向盘按键角色、已存 Wi-Fi 凭据）。
无 adb 时可直接拷 U 盘，用车机文件管理器安装（需允许「未知来源」）。

### 方向盘按键

**上一首 / 下一首开箱即用**，不需要任何设置。

> 星瑞方向盘**没有播放 / 暂停键** —— 那个位置是车机自己的**飞屏键**，
> 只经厂商 AIDL 送到 `PopView`，**从不进入 Android 按键管线**，任何应用都够不着。

## 与官方 0.2.9 / 0.2.12 的差异

**本版不等于官方 DiPlay。** `-geely-rc` 表示「Geely 线自己的候选版」。

官方近几个版本的头条功能**几乎全部依赖比亚迪 DiLink**，吉利 E01 上无对应硬件或平台不可行，
本版**均未包含**：中控悬浮地图、仪表盘显示 CarPlay 歌曲、launcher 导航 widget、
Android 11+ launcher 内嵌地图、BYD 昼夜模式、环视续连。

**Wi-Fi Direct** 相关（组管理重写、首选信道）为 **API 29+** 能力，E01 是 API 22，**平台够不着**。

**缓冲音频**（`BufferedAudioStream`）**不做** —— 它本质是拿内存换抗卡顿，
而这台车 `MemFree` 常态只有 **26–33 MB**，上游自己也默认关闭。

**Same LAN（现有 Wi-Fi）** 经复查**在本车可行**（只需三处 API 垫片），但**尚未移植**。
